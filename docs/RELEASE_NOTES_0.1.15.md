日本語

現在のバッテリー情報を専用タブへ移しました。概要ではペアリング済み端末の一覧を先頭に表示します。現在値の表・詳細・今すぐ取得／送信は「現在のバッテリー」で利用できます。PC画面からの定期取得はそのタブを表示している間だけ行い、スマホからの更新要求は引き続き受け付けます。アルファ版インストーラーはコード署名されていません。

English

Live Battery now has its own tab. Overview starts with the paired-device list. Current values, optional details and Receive/Send Now are available in Live Battery. Desktop viewing refreshes run only while that tab is visible; mobile refresh requests remain supported. The alpha installer is not code signed.
