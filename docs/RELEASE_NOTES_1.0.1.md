# MochiLog Windows 1.0.1

## 日本語

- ペアリングや接続に失敗したときの記録と、接続先の選び方を改善しました。
- ペアリング前でもサポート用の情報を作成できるようになりました。
- サポートへ添付する情報を1つのZIPにまとめ、発生日時に応じたログと設定情報を含められるようになりました。

スマホ版MochiLog 4.1.0とあわせて更新してください。既存のペアリング・設定・保管済みログは引き継ぎます。Windows 11 x64に対応し、必要な実行環境を同梱しています。

通常は `MochiLog-Windows-Setup.exe` を使用してください。`MochiLog-Windows-Alpha-Setup.exe` は旧版の自動更新用で、内容は同一です。

インストーラーはコード署名されていません。SHA-256は添付の `SHA256SUMS.txt` で確認できます。

## English

- Improved pairing/connection diagnostics and connection candidate selection.
- Support information can now be prepared before pairing is completed.
- Support attachments are bundled into one ZIP with dated logs and relevant settings information.

Update alongside MochiLog mobile 4.1.0. Existing pairings, settings and stored logs are preserved. Supports Windows 11 x64 and includes the required runtime.

Use `MochiLog-Windows-Setup.exe` for a normal installation. `MochiLog-Windows-Alpha-Setup.exe` contains identical bytes for older automatic updaters.

The installer is not code-signed. Checksums are provided in `SHA256SUMS.txt`.
