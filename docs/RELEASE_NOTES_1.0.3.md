# MochiLog Windows 1.0.3

## 日本語

・無線接続と診断サービスの互換性を改善しました。
・ログ収集に失敗した際、以前の成功結果が残る問題を修正しました。

既存のペアリングと保存済みログを引き継ぎます。対応環境はWindows 11です。
Pythonと必要なライブラリは同梱しています。別途Pythonを導入する必要はありません。
インストーラーにはAuthenticode署名がありません。

## English

• Improved compatibility with wireless connections and diagnostic services.
• Fixed stale successful results remaining after a failed log collection.

Existing pairings and stored logs are preserved. Requires Windows 11.
Python and the required libraries are bundled; a separate Python installation is not needed.
The installer is not Authenticode-signed.
