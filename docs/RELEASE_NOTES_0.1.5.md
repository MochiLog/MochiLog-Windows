# MochiLog Windows 0.1.5 Alpha

## 日本語

初回のUSB信頼設定に進行状況を表示し、Apple DevicesがiPhone・iPadを認識しない場合の復旧案内を追加しました。復旧操作の後は端末の検出を再試行できます。ペアリングが完了するとQRコードは自動で閉じ、連携済み端末を確認できます。

対応するMochiLogのiOS/iPadOSベータ版と組み合わせると、必要な当日のログを受け取った後は自動収集を翌日まで休止します。「今すぐ収集」は引き続き使えます。

Windows 11とiOS/iPadOS 27向けのアルファ版です。初回のUSB信頼設定にはApple DevicesまたはApple公式サイトのクラシック版iTunesが必要です。解析ログの収集時は端末をロック解除してください。このインストーラーは現在コード署名されていません。

## English

USB trust setup now shows progress and offers guided recovery when Apple Devices does not recognize an iPhone or iPad. Device detection can be retried after recovery. The pairing QR code closes automatically when pairing succeeds, and paired devices remain visible.

With a compatible MochiLog iOS/iPadOS beta, automatic collection pauses until the next day after the required daily logs have been received. Manual collection remains available.

This alpha supports Windows 11 and iOS/iPadOS 27. Initial USB trust requires Apple Devices or the classic iTunes installer from Apple's website. Keep the device unlocked while collecting analytics logs. The installer is not currently code signed.
